# LSE Ecuador - Sistema de Reconocimiento de Lenguaje de Señas

## 📋 Resumen del Proyecto
Sistema funcional de reconocimiento de Lengua de Señas Ecuatoriana (LSE) con interfaz gráfica.

## 🚀 Características Principales
✅ **Grabación de Dataset**: Captura de gestos LSE
✅ **Entrenamiento IA**: Modelo optimizado con TensorFlow
✅ **Reconocimiento en Tiempo Real**: Traducción instantánea
✅ **Interfaz Elegante**: GUI moderna con Tkinter
✅ **Sistema Robusto**: Manejo de errores y logging

## 🎯 Gestos Reconocidos
- 🖐️ **HOLA**: Mano abierta hacia adelante
- 👋 **ADIOS**: Movimiento lateral de mano
- 🙏 **GRACIAS**: Mano hacia el pecho
- 👍 **SÍ**: Puño vertical (arriba-abajo)
- 👎 **NO**: Dedo horizontal (izquierda-derecha)

## 🏃‍♂️ Inicio Rápido
1. **Activar entorno**: `INICIAR_ENTORNO.bat`
2. **Ejecutar sistema**: `EJECUTAR_LSE.bat`
3. **Solo reconocimiento**: `EJECUTAR_RECONOCIMIENTO.bat`
